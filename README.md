# ✦ CodeChain

CodeChain is a blockchain-powered DSA learning platform where users solve Data Structures and Algorithms problems and earn CCT (CodeChain Token) rewards for successful submissions.

The platform combines MERN stack development with Web3 technologies to create a decentralized and rewarding coding ecosystem.

---

# 🚀 Features

## 🔐 Authentication
- User Signup & Login
- JWT Authentication
- Secure Sessions

## 💻 DSA Problem Solving
- Dynamic Problem Listing
- Problem Details Page
- Code Editor Interface
- Submission Verification

## 🏆 Reward System
- Token-based rewards
- Wallet Integration
- Real-time reward tracking

## 📊 Dashboard
- User statistics
- Problems solved
- Token balance
- Wallet status

## 🥇 Leaderboard
- Dynamic ranking system
- Global score tracking

## 👛 Wallet Integration
- MetaMask Wallet Connect
- Polygon Amoy Network
- CCT Token Support

## ⚙️ Admin Panel
- Add DSA Problems
- Manage Platform Content

# ⚡ Installation

## Clone Repository

```bash
git clone <your-repo-link>
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create `.env` file inside backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```
